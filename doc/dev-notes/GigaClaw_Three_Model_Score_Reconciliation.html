GigaClaw Ecosystem Analysis — Three-Model Score Reconciliation

85 unified line items from three independent analyses · every score as given, totals as computed, plus an adjudicated column after adversarial review · 30 July 2026

The total is in the table. It is also the least meaningful number there.

The scale isn't additive. A 1 means "we already win"; a 5 means "we have a hole." Summing them produces verdicts nobody rendered. T16 (zero-trust federation) scores 2/2/5 and totals 9 — identical to P22's unanimous 3/3/3. One is a rejected idea plus one outlier; the other is a settled consensus. 53% of all marks are 4 or 5, so the scale barely discriminates before you average it.

Coverage isn't judgment. Blanks mean "not covered," never zero. Gemini scored 26 of 85 items, Claude 54, Codex 57 — so any total-based ranking is gated by the shortest and least source-verified list. P3, the only finding with a live security consequence, went unscored by Gemini and was thereby demoted below adding 80 markdown files about influencer marketing.

The three aren't independent. All three received the same prompt, which supplied both the gap-seeking frame and the definition of a "5." Claude and Codex agree on 62% of shared items; Gemini agrees with each on roughly 33%, barely above chance. This is two correlated source-audited analyses plus one weakly-correlated documentation reader — not three votes.

How reliable is each analysis

A

Codex

Pins all five repos to commit SHAs. Permalinks with line ranges into source, not READMEs. Separates audited counts from published claims (204 local agent files vs README's 203). Shows its jq / rg / comm commands. Found a real defect nobody else did. The evidentiary spine.

A−

Claude

Real verification appendix; re-counted agents, automations, teams. Surfaced ruflo's own in-tree audit grading its headline claims FABRICATED. Deductions: paths without line numbers or SHAs, a 12-vs-13 arithmetic slip, one over-generous self-score on teams. The strongest synthesis.

D

Gemini

No SHAs, no stated method, no README-vs-code distinction. Citations point at unresolvable local IDE scratch paths, and the named file path routinely differs from the linked target. Calls ruflo "Rust-powered" when its Cargo.toml says otherwise. Lists 32 agents and says 34; says "5 harnesses" and lists 6. Usable only where another analysis independently confirms it.

This grading is why the Adj. column exists. Gemini's uncorroborated ruflo scores — federation 5, consensus 4, queen 4, GOAP 5, sub-millisecond HNSW 5 — all rest on a repo whose own in-tree audit graded its headline benchmarks fabricated: "HNSW 150x" measured 1.48x, and Flash-Attention speedups were Math.random(). Both source-verified analyses independently found that ruflo's agent_spawn writes a coordination record rather than spawning a worker. Gemini never mentions this, and its entire swarm / queen / consensus / federation block presumes real spawning.

Final ranked priority list

All three analyses ranked coverage gap, not priority — Codex says so outright. This list converts gap into priority, and the ordering is dependency-driven, not score-driven. The highest raw total in the table (14, the marketing cluster) lands in Tier 4 as a pattern-only adoption. The item that ranks 16th by raw score is #1 here.

TIER 0 — Foundation. Nothing above this is real until these ship.

P3 · U18 · U17
Enforce contracts at the runner boundary
GigaClaw launches Claude with permissions skipped, and enforces allowedWriteGlobs, riskClass and ticketExit by injecting them into the prompt. Every other governance feature in the system — approval gates, ADR receipts, typed verdicts, risk classes, the opus gatekeeper — audits a process it cannot stop. An agent that ignores its glob still produces a passing receipt. Blocking git --no-verify and dry-running outbound CMS calls are the same hook, same code path.
Cost / gate: Build 2–4 days. Tail 1–2 weeks: those 33 glob sets have never been evaluated against reality, so most are wrong and dispatches will start failing on day one. Those failures are the real deliverable — your first honest inventory of what each agent actually touches.
P20
Typed catalog with CI-enforced counts
The three analyses produced four disagreements about GigaClaw's own inventory. You cannot trust any count — including your README's — until a generated catalog fails CI on mismatch. Replaces check-automation-drift.sh.
Cost / gate: Days. Prerequisite for honestly measuring anything else.
T17 · P22
The two cheap defects
content-writer is in zero specialty teams. models.json covers ~12 of 33 agents with no stated criteria. Both are hours of work, and both are evidence the 33-agent moat is less bound than the analyses assume.
Cost / gate: Hours.

TIER 1 — Make governance mean something

A11 · P8
Typed SHIP / FIX / BLOCK verdicts
Highest-consensus actionable finding in the set (4/4/5), and the one Gemini 5 both source-verified analyses corroborate. blog-reviewer, ui-auditor, qa-tester, local-media-reviewer and evaluator emit prose rubrics. Convert to versioned JSON verdicts with per-category scores and hard veto items, validated by scripts/content_contract.py — the enforcement point already exists.
Cost / gate: Low. The reviewers already run; you are changing an output format, not adding a pipeline.
U10
Bounded repair loop
Auto re-dispatch on FIX up to N times, escalate to the owner on exhaustion. Meaningless before typed verdicts exist; nearly free after.
Cost / gate: Small, strictly after A11.
O6
Agent eval harness
gigaclaw eval <agent>: static checks → LLM judge → optional Monte Carlo with confidence intervals. You have no way to benchmark an agent before trusting it with dispatches. Also the hard prerequisite for any routing work.
Cost / gate: Medium.
A3
security-auditor — this one agent, not the DevOps catalog
Unanimous blind spot across both source-verified analyses. Add with a contract entry, a model assignment, a team membership and a Review-column automation. A4's kubernetes / cloud-architect / terraform roster is adjudicated down from 5 to 3 — there is no deploy target.
Cost / gate: Small.
